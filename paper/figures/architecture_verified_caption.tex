VisTacFusion with paired tactile and visual inputs.
Frozen SITR-B/16 and MAE-L/16 encoders supply tactile features and visual
memory, respectively. Four intermediate tactile features feed independent
gated cross-attention modules conditioned on the final visual bottleneck
$B_4$. DPT reassembles the tokens into four resolutions and progressively
fuses them into a shared $112\times112$ feature map; separate heads predict
depth and surface normals. The pose branch projects the final tactile
features into 196 spatial queries and one pose query initialized from the
tactile CLS token. Each of four fusion layers updates the bottleneck from
fixed visual memory, then updates the queries through cross-attention and
self-attention. Bottleneck and query states carry across layers; only $B_0$
is a learned initialization. The pose head concatenates the final pose token
with the mean of the 196 spatial queries. Dashed arrows indicate conditioning;
the line bridge denotes a crossing without a connection. Labels $2\times$
denote upsampling. Calibration inputs and modality, position, and object-ID
embeddings are omitted for clarity. Token glyphs are schematic; geometry
thumbnails are ground-truth examples illustrating output types.

\section{Related Work}

\noindent\textbf{Tactile simulation and sim-to-real.}
Physically based renderers synthesize GelSight-type images from mesh contacts~\cite{agarwal2021simulation,wang2022tacto,si2022taxim,chen2023tacchi,xu2022efficient,akinola2025tacsl}; learned renderers map simulated depth to sensor images with an image-to-image network~\cite{isola2017pix2pix,church2022tactile,zhong2025tactgen}. Unpaired translation closes the remaining gap with adversarial, cycle or contrastive constraints~\cite{shrivastava2017simgan,zhu2017cyclegan,park2020cut} and has been applied to tactile images~\cite{chen2022cyclegan,azulay2024sightgan,higuera2023braille}; domain randomization trades fidelity for robustness~\cite{tobin2017domain}. These works report gains from synthetic data but rarely state which real frames the renderer saw relative to the test set, nor charge its real data against the downstream budget. Sensor-invariant representations~\cite{gupta2025sitr,zhao2024transferable,higuera2024sparsh} attack sensor specificity on the feature side; we use one~\cite{gupta2025sitr} as a frozen backbone so that our comparison isolates the data.

\noindent\textbf{Pseudo-labeling and render-and-compare.}
Self-training on a model's own predictions~\cite{lee2013pseudo,xie2020noisy} is the standard way to use unlabeled data, but its labels inherit the model's errors. Object pose estimation refines a pose hypothesis by comparing a render of the model with the image, iteratively and with a learned update~\cite{li2018deepim}, and can self-supervise on unlabeled real images~\cite{wang2020self6d}. MAPL brings the two together for tactile sensing: the pseudo label of a frame is not a network output but the object mesh at a pose found by a learned residual aligner, and the aligner is trained from the few labeled tactile frames alone, without a differentiable or photorealistic renderer.
